### What's new

- **Help & support, built in** — report a problem or send feedback straight from the app. Follow the reply in an in-app conversation, get a badge when there's a new message, and track everything under "My reports" — no account and no browser needed.
- **A gentler start** — a short, skippable intro on first launch explains the idea in three screens (re-openable any time from Settings), and one-time tips quietly point out the less obvious controls the first time you reach them.
- **"Ready by" is now a smart default** — set a deadline and SweetSpot starts on the cheapest time that still finishes on time, while **Earlier** and **Cheaper** let you browse around it. The results screen is now simply "Recommended time".
- **More reliable prices** — an empty response from one data source now falls through to the next, disabled sources are always respected, and a few Wear OS edge cases (a frozen countdown, an unknown zone) are fixed.
- **Clearer wording, in your language** — a top-to-bottom pass over all 25 languages for consistent terminology and a natural, consistent level of formality throughout.

Thanks for using SweetSpot!
