{{< changelog version="6.5" date="15 Ιουλίου 2026" >}}
- Ομαδοποιήστε τα κουμπιά των συσκευών ανά τύπο — σε γραμμές ή στήλες — ώστε τα προγράμματα της ίδιας συσκευής να μένουν μαζί. Τα οχήματα μπορούν να έχουν δική τους ενότητα πάνω ή κάτω.
{{< /changelog >}}

{{< changelog version="6.4" date="14 Ιουλίου 2026" >}}
- Μοιραστείτε τη διαμόρφωσή σας: αντιγράψτε τις συσκευές σας, τη σειρά τους και τις ρυθμίσεις φόρτισης ηλεκτρικού οχήματος σε άλλο τηλέφωνο σαρώνοντας έναν κωδικό QR ή στέλνοντας έναν σύνδεσμο — χωρίς λογαριασμό, λειτουργεί εκτός σύνδεσης. Το άλλο τηλέφωνο εμφανίζει μια προεπισκόπηση όπου μπορείτε να προσθέσετε, να αντικαταστήσετε ή να επιλέξετε τι θα εισαγάγετε.
{{< /changelog >}}

{{< changelog version="6.3" date="13 Ιουλίου 2026" >}}
- Ταξινομήστε και αναδιατάξτε τις συσκευές σας: σύρετέ τες στη δική σας σειρά ή ταξινομήστε κατά Πιο συχνά, Πιο πρόσφατα, Όνομα, Διάρκεια ή Τύπο.
- Τα «Πιο συχνά» και «Πιο πρόσφατα» μετρούν τα πατήματα τόσο στο τηλέφωνο όσο και στο ρολόι σας.
- Επιλέξτε πού εμφανίζονται τα οχήματα ανάμεσα στις συσκευές: Ανάμεικτα, Πρώτα, Τελευταία ή σε Ξεχωριστή ενότητα.
- Τα οχήματα δείχνουν πλέον εικονίδιο αυτοκινήτου και οι πηγές δεδομένων αναδιατάσσονται κι αυτές σύροντας.
{{< /changelog >}}

{{< changelog version="6.2" date="12 Ιουλίου 2026" >}}
- Ανασχεδιασμένες ρυθμίσεις: ένα τακτοποιημένο μενού κατηγοριών, καθεμία με το δικό της εικονίδιο και τη δική της οθόνη — Συσκευές, Φόρτιση ηλεκτρικού οχήματος, Τελική τιμή, Περιοχή (χώρα, ζώνη τιμών, ζώνη ώρας), Εμφάνιση (γλώσσα, θέμα) και Για προχωρημένους. Όλα βρίσκονται πιο εύκολα από τον προηγούμενο έναν μακρύ κατάλογο και, επιστρέφοντας από μια λίστα επιλογής, διατηρείται η θέση σας.
{{< /changelog >}}

{{< changelog version="6.1.1" date="12 Ιουλίου 2026" >}}
- Βελτιώσεις στην τελική τιμή: το πεδίο προσαύξησης δείχνει πλέον το νόμισμά σας (π.χ. €/kWh), οι ρυθμίσεις διατηρούν τη θέση κύλισης όταν επιστρέφετε από μια λίστα επιλογής και, αν η τελική τιμή είναι ενεργή, σας υπενθυμίζει να επιλέξετε προμηθευτή ή να εισαγάγετε προσαύξηση πριν φύγετε.
{{< /changelog >}}

{{< changelog version="6.1" date="12 Ιουλίου 2026" >}}
- Τελική τιμή (Κάτω Χώρες): προαιρετικά εμφανίστε την πλήρη τιμή καταναλωτή — τη χονδρική τιμή συν τον ενεργειακό φόρο, την προσαύξηση του προμηθευτή σας και τον ΦΠΑ — αντί για τη σκέτη τιμή αγοράς. Επιλέξτε τον προμηθευτή σας ή εισαγάγετε τη δική σας προσαύξηση στην «Τελική τιμή» στις ρυθμίσεις. Δεν αλλάζει ποτέ ποια χρονική περίοδος είναι η φθηνότερη· απλώς δείχνει ρεαλιστικό κόστος λειτουργίας.
{{< /changelog >}}

{{< changelog version="6.0.1" date="25 Ιουνίου 2026" >}}

{{< changelog version="6.0" date="23 Ιουνίου 2026" >}}
- Φόρτιση ηλεκτρικού οχήματος: προσθέστε το αυτοκίνητό σας, εισαγάγετε την τρέχουσα και την επιθυμητή φόρτιση και το SweetSpot βρίσκει τη φθηνότερη ώρα για να το βάλετε στην πρίζα και πόσο θα διαρκέσει.
- Ώρα «Έτοιμο έως»: ολοκληρώστε οποιαδήποτε συσκευή ή φόρτιση πριν από μια προθεσμία που ορίζετε εσείς.
- Ονομαστική ισχύς: ορίστε την ισχύ μιας συσκευής σε kW ώστε η εκτίμηση κόστους να αντικατοπτρίζει την πραγματική της κατανάλωση.
